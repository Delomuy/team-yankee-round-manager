Icons for the models in the Battle tab.

Put PNG / JPG / WEBP pictures here, named after:
  - a card id        TU102.png   -> every model of that card
  - a type letter    I.png       -> every model of that type that has no card icon
                     (I infantry, T tanks, A artillery, C carriers / transports, H helicopters, P planes)

You can also set a card's icon inside the game: Battle tab -> click a unit's name -> "Set icon...".
Models without a picture show a small drawn symbol for their type.
